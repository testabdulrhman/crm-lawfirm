# شاشة عرض المكتب (تلفزيون سامسونج / Tizen)

صفحة واحدة تعرض بث الكاميرا + جلسات اليوم + المهام المفتوحة.

## التشغيل

1. انسخ `index.template.html` إلى `index.html`
2. املأ في كتلة `CONFIG` أعلى الـscript:
   - `SUPABASE_ANON` — مفتاح anon من إعدادات المشروع
   - `BOARD_SECRET` — القيمة المخزَّنة في `lookup_values` (type=`tv_board_config`)
   - `CAMERA_URL` — رابط go2rtc على الـiMac (⚠️ عنوانه يتغيّر — احجز له عنواناً
     ثابتاً في الراوتر)
3. شغّل خادماً بسيطاً على الجهاز نفسه:
   ```bash
   python3 -m http.server 8080 --bind 0.0.0.0
   ```
4. في متصفح التلفزيون: `http://<عنوان-الجهاز>:8080/index.html`

## ⚠️ لماذا محلياً لا على الاستضافة

رابط الكاميرا `http://` والموقع `https://` — المتصفح يحجب المحتوى المختلط
فلا يظهر البث إطلاقاً لو رُفعت الصفحة على الاستضافة. وميزة إضافية: بيانات
المكتب لا تغادر الشبكة.

## البيانات

عبر دالة `tv-board` لا بقراءة الجداول مباشرةً: مفتاح anon منشور في كود الموقع،
وسياسات `sessions`/`tasks`/`cases` لدور `authenticated` فقط — ففتحها لـanon
كان سيُظهر عناوين القضايا والمحاكم لأي أحد على الإنترنت. الدالة تُرجع الحد
الأدنى للعرض فقط خلف سر مستقل.

`index.html` (النسخة الحيّة) مستثناة من git لأنها تحمل المفتاح والسر.
