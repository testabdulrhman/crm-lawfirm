# CRM — شركة عبدالرحمن بن رضوان المشيقح للمحاماة وإدارة إجراءات الإفلاس

نظام إدارة مكتب محاماة (الإصدار v2). واجهة عربية كاملة (RTL) بخط IBM Plex Sans Arabic، منشور على **app.redwan.sa**.

## التقنيات

- React 19 + TypeScript + Vite 6
- Tailwind CSS 3.4 + shadcn/ui
- Wouter (routing) · Zustand (الحالة) · TanStack Query v5 (البيانات)
- React Hook Form + Zod (النماذج والتحقق)
- Supabase JS v2 (Auth + Database + Storage + Edge Functions)
- Lucide React (الأيقونات) · recharts (الرسوم)

## الهوية البصرية

- الكحلي `#111D3A` · الذهبي `#C9A84C` · خلفية بيج `#F8F7F4`
- الوضع الليلي مدعوم عبر `class` على `<html>`.
- أرقام لاتينية في كل المكان (`fmtNumber`)، وتقويم مزدوج هجري/ميلادي (`DualDatePicker` + `fmtDatePref`).

## جاهزية iOS (Capacitor)

التطبيق مبنيّ «Capacitor-ready» للتغليف لاحقاً كتطبيق iOS أصلي دون إعادة هيكلة:

- **Hash routing** عبر Wouter (`useHashLocation`) — الروابط بصيغة `/#/...` لتعمل من `file://`.
- **`base: './'`** في `vite.config.ts` — أصول بمسارات نسبية.
- **مناطق آمنة** — `viewport-fit=cover` + utility classes (`.pt-safe` / `.pb-safe` …) مطبّقة على `TopBar` و`Sidebar`.
- **طبقة تخزين** `src/lib/storage.ts` — تُستبدل لاحقاً بـ Capacitor Preferences (ملف واحد).
- **طبقة ملفات** `src/lib/files.ts` — اختيار/رفع إلى Supabase Storage، تُوسّع بـ Camera/Filesystem.
- **روابط خارجية** عبر `openExternal()` في `src/lib/external.ts` — تُستبدل بـ Capacitor Browser.
- **مناطق لمس ≥44px** وتصميم mobile-first (~390px)؛ الجداول تتحوّل لبطاقات على الجوال.

## الوحدات (منجزة ومنشورة)

- **تسجيل الدخول** — كلمة مرور أو **رمز OTP عبر الجوال (SMS)**؛ الربط عبر `team_members.auth_id`.
- **لوحة التحكم = مركز قيادة** — مبدّل «متطلباتي/المكتب»، بطاقات KPI قابلة للنقر، «مهامي» بإكمال فوري، تنبيه «جلسات تحتاج إغلاق».
- **القضايا** — قائمة صفوف بفلاتر/بحث، وتفاصيل بتبويبات:
  - نظرة عامة · **الأطراف** (المدّعون/المدّعى عليهم) · **الجلسات** · **الأحكام** · المهام · المذكرات · **المستندات** (بطاقات).
  - **الجلسات:** حالة تلقائية حسب الوقت، رقم الجلسة، تنبيه تاريخ غير منطقي، و**«إغلاق الجلسة»** (محضر + مرفق + تقرير للعميل SMS/واتساب + خطوة قادمة تُنشئ جلسة/مهمة/تُقفل القضية).
  - **ذكاء اصطناعي:** تعبئة بيانات الحكم من الصك، وتعبئة محضر الجلسة والخطوة القادمة من المحضر تلقائياً (PDF/صورة).
- **الجلسات** — صفحة شاملة لكل الجلسات عبر القضايا (`/sessions`).
- **جهات الاتصال** — قائمة/تفاصيل، سجل التواصل (مكالمات هاتف)، و«الارتباطات» القابلة للنقر لصفحاتها.
- **الوكالات (POA)** — مع تنبيه الانتهاء القريب.
- **الاستشارات واللوائح** — مع مرفقات متعددة.
- **التوثيق العقاري** — مع مرفقات (حذف ناعم للمدير).
- **المواعيد** — تأكيد SMS + مزامنة Google Calendar.
- **الصادر** — الخطابات الصادرة.
- **الطلبات الواردة** — استقبال ومتابعة.
- **طلبات التوظيف** — من نموذج الموقع، مع **تحليل بالذكاء الاصطناعي** (قراءة السيرة PDF)، ورفض/إعادة عبر SMS.
- **التقارير والإحصاءات** — رسوم recharts.
- **الإعدادات** — بيانات المكتب (`office_info`) · التصنيفات (`lookup_values`) · **قوالب الرسائل** · المظهر.
- **الموظفون** — عرض/إضافة/تعديل/تبديل الحالة (إنشاء الحساب عبر Edge Function).

## التكاملات و Edge Functions (Supabase)

- **`ai-assistant`** (Claude) — تحليل المتقدّمين، استخراج بيانات الأحكام، استخراج محاضر الجلسات.
- **`swift-endpoint`** — إنشاء/حذف مستخدم + إرسال SMS عبر Msegat (البيانات تُحلّ خادميّاً).
- **`staff-login-otp`** — دخول الموظف برمز OTP عبر الجوال.
- **`calendar-sync`** — مزامنة المواعيد/الجلسات مع Google Calendar.
- **`submit-application`** — استقبال طلبات التوظيف من نموذج الموقع العام.
- **`hatif-webhook`** — استقبال سجلّ المكالمات من هاتف/Voxa وربطها بجهات الاتصال.
- **`hatif-sync` / `hatif-bulk-sync`** — دفع جهات الاتصال إلى دفتر هاتف.
- كل الأسرار (Google / Msegat / Anthropic / Hatif webhook) في **Supabase Secrets** — لا مفاتيح في الكود.
